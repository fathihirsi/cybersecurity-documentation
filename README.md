## Portfolio Principles

The documentation in this repository is built around five principles:

**1. Evidence-driven**

Security decisions should be supported by observable evidence.

**2. Risk-based**

Technical findings should be evaluated according to business impact and likelihood.

**3. Repeatable**

Security procedures should be documented so that another analyst can follow the same process.

**4. Measurable**

Security activities should produce meaningful outputs that can be reviewed and improved.

**5. Continually improved**

Processes should be updated based on incidents, findings, lessons learned and changes in the environment.
